# Hashir A — Developer Calling Card

A responsive, one-page personal website that introduces me as a software developer and links to my LinkedIn and GitHub profiles.

[View the live website](https://hashir-a-calling-card.vercel.app/)

The design pairs pixel-style lettering with a lined-paper background, pastel skill tags, and subtle animations. Built with v0 and Next.js, and deployed on Vercel.
